# Lista de Mercado (Flutter)

[English](#english) · [Português](#português)

## English

A Flutter app for organizing shopping lists, built as a mobile development study project.

### Features

- Create and delete multiple shopping lists
- Add items with a quantity, edit the quantity, and remove items
- Mark items as bought
- Search items by name within the selected list
- Login, sign-up, password recovery, and "About" screens (interface only, there is no real authentication)

Data is kept in memory, so lists reset when the app restarts.

### Tech

- Flutter / Dart (SDK >= 3.3)
- Material Design
- Named-route navigation
- [`device_preview`](https://pub.dev/packages/device_preview) to preview the layout on different devices

### Running

```bash
flutter pub get
flutter run
```

## Português

Aplicativo Flutter para organizar listas de compras, desenvolvido como projeto de estudo de desenvolvimento mobile.

### Funcionalidades

- Criar e excluir várias listas de compras
- Adicionar itens com quantidade, editar a quantidade e remover itens
- Marcar itens como comprados
- Pesquisar itens pelo nome na lista selecionada
- Telas de login, cadastro, recuperação de senha e "Sobre" (somente interface, sem autenticação real)

Os dados ficam em memória, então as listas são reiniciadas ao fechar o app.

### Tecnologias

- Flutter / Dart (SDK >= 3.3)
- Material Design
- Navegação com rotas nomeadas
- [`device_preview`](https://pub.dev/packages/device_preview) para visualizar o layout em diferentes dispositivos

### Como executar

```bash
flutter pub get
flutter run
```
